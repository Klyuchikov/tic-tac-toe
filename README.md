# Крестики-Нолики

Простая игра "крестики-нолики" на чистом HTML, CSS и JavaScript.

## Описание

Игра для двух игроков на поле 3x3. Игроки ходят по очереди, ставя X или O. Определяется победитель или ничья. Ведётся счёт побед и ничьих.

## Функции

- Игровое поле 3x3
- Очередные ходы X и O
- Определение победителя и ничьи
- Подсветка выигрышной линии
- Счётчик побед X, O и ничьих
- Кнопка "Новая игра" и "Сбросить счёт"
- Адаптивный дизайн для мобильных устройств

## Запуск

1. Скачай или клонируй репозиторий.
2. Открой файл `Index.html` в браузере.
3. Играй!

## Файлы

- `Index.html`: Структура страницы
- `style.css`: Стили и адаптация
- `script.js`: Логика игры
